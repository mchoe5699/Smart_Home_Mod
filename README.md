# Smart Home Mod (Forge 1.20.1)

아파트 홈네트워크를 재현하는 마인크래프트 모드입니다. 모든 기기는 **우클릭하면 실물 모양의 조작화면**이 열립니다.

## 기기
| 구분 | 기기 | 조작화면 / 기능 |
|---|---|---|
| 세대 내부 | 월패드 | 터치스크린 홈네트워크: 방문자(현관 영상), 조명, 난방, 가스, 환기, 엘리베이터, 외출/방범, 경비실, 세대 통화, 기록, 공지, 설정(세대 비밀번호) |
| | 비디오폰 | 왼쪽 화면 + [모니터][통화][문열림][경비실][인터폰][종료] |
| | 인터폰 | 수화기형 음성 전용, LCD + 키패드 |
| 세대 외부 | 도어카메라 | 영상 + 음성 송출 |
| | 도어폰 | 음성만 송출 |
| | 로비폰 | 카메라·LCD·키패드·[호출][경비실][취소][열쇠]·RF 카드 리더 |
| | 경비실기 | 관제 콘솔: 모니터(호출 영상·CCTV), 호출 대기 목록, 키패드, 수화기 |
| 관리 | 단지 대시보드 | 큰 지도에서 구획 편집 |
| | 관리 컴퓨터 | 단지 현황, 카드 등록·관리, 비밀번호, 공지사항 |
| 세대 설비 | 스마트 조명·온도조절기·가스밸브·환기장치·엘리베이터 호출 연동기 | 같은 동·호의 월패드에서 제어 |

## 단지 대시보드
- 지도 위를 **누르고 끌면** 새 구획(단지)이 생깁니다.
- 구획을 **클릭**해 여러 개 선택 → **[묶기]**로 같은 단지, **[분리]**로 각각 다른 단지.
- 같은 단지의 구획이 맞닿으면 **맞닿은 부분의 경계선이 사라져** 하나의 단지 모양으로 보입니다.
- 모든 연동(호출·카드·비밀번호·설비)은 **같은 단지 안에서만** 됩니다.

## 통화
- 통화가 연결되면 조작화면 오른쪽에 **대화창**이 열리고, 입력하면 상대 기기로 전달됩니다(근처 채팅도 전달).
- 도어카메라·로비폰에서 온 호출은 월패드·비디오폰·경비실기 화면에 **실시간 영상**으로 나옵니다.

## 번호 (0~9999)
- 월패드·비디오폰·인터폰: 관할경비실 + 동 + 호 / 로비폰: 관할경비실 + 동 + 로비번호 / 경비실기: 경비실번호
- 경비실 호출은 관할경비실 번호가 같은 경비실기 우선.
- 로비폰은 동 번호가 같은 세대 호출, 동 9999(단지 외곽)는 단지 안 모든 동·호 호출.

## 공동현관 출입
- 공용 비밀번호: 로비폰 [열쇠] → 번호 → `#`
- 세대 비밀번호: [열쇠] → `호*번호` → `#` (외곽 로비폰은 `동*호*번호`)
- 카드: 관리 컴퓨터에서 **카드등록용 카드**를 등록하면 **출입용 카드**가 나옵니다. 카드를 들고 로비폰 우클릭.

## 빌드
`./gradlew build` → `build/libs/`. push 할 때마다 GitHub Actions가 jar를 `build-output` 브랜치에 올립니다.
