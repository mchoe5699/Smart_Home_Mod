# Smart Home Mod (Forge 1.20.1)

아파트 홈네트워크를 재현하는 마인크래프트 모드입니다.

## 기기 구성
| 구분 | 기기 | 설명 |
|---|---|---|
| 세대 내부기기 | 월패드 | 방문자 영상·음성, 경비실 호출, 세대 호출, 문열림, 통화 기록 |
| | 비디오폰 | 방문자 영상·음성, 경비실/세대 호출, 문열림 |
| | 인터폰 | 음성 전용 |
| 세대 외부기기 | 도어카메라 | 세대 내부기기로 **영상 + 음성** 송출 |
| | 도어폰 | 세대 내부기기로 **음성만** 송출 |
| | 로비폰 | 공동현관. 세대·경비실 호출, 문열림 시 레드스톤 출력 |
| | 경비실기 | 세대·로비폰 호출, 들어온 호출 목록 |
| 관리 | 단지 대시보드 | 단지 이름과 구획(X/Z 범위) 설정, 구획 안 기기 목록 |

## 번호 설정 (모든 번호 0~9999)
- 로비폰·인터폰·비디오폰·월패드 조작화면에는 **설정 버튼 하나**가 있습니다.
  - 월패드·비디오폰·인터폰: 관할경비실 번호 + 동 번호 + 호 번호
  - 로비폰: 관할경비실 번호 + 동 번호 + 로비 번호
- 경비실기: 경비실번호 설정 버튼
- 도어카메라·도어폰: 연결할 세대번호(동·호)

## 연동 규칙
- 모든 연동은 **단지 대시보드에서 설정한 구획 안**의 기기끼리만 이루어집니다.
- 경비실 호출 시 **관할경비실 번호와 같은 경비실기를 우선** 호출합니다. 없거나 통화 중이면 단지 내 다른 경비실기로 연결됩니다.
- 월패드·비디오폰·인터폰·로비폰은 **관할경비실 번호가 같을 때** 서로 연동됩니다.
- 로비폰은 **동 번호가 같은 세대**를 호출합니다.
- 동 번호를 **9999**로 설정한 로비폰은 단지 외곽 출입용으로, 단지 안 **어느 동·호든** 호출할 수 있습니다.
- 경비실기는 단지 안 모든 세대와 로비폰을 호출할 수 있습니다.

## 통화
- 호출 → 세대의 같은 동·호 내부기기가 모두 울리고, 한 기기에서 받으면 연결됩니다.
- 연결 중에는 기기 근처(6블록)에서 채팅하면 상대 기기 근처로 전달됩니다(음성 통화).
- 영상: 카메라 기기(도어카메라·로비폰) 앞에 선 플레이어 얼굴이 월패드·비디오폰·경비실기 화면에 표시됩니다.
- 문열림: 로비폰·도어카메라·도어폰이 5초간 레드스톤 신호를 냅니다.

## 빌드
`./gradlew build` → `build/libs/`. GitHub Actions가 push마다 jar를 빌드해 `build-output` 브랜치에 올립니다.
