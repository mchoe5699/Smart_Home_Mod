# Smart Home Mod (Forge 1.20.1)

아파트 홈네트워크를 재현하는 마인크래프트 모드입니다. 모든 기기는 **우클릭하면 실물 모양의 조작화면**이 열립니다.

## 기기
| 구분 | 기기 | 조작화면 / 기능 |
|---|---|---|
| 세대 내부 | 월패드 | 터치스크린 홈네트워크: 방문자(현관 영상), 조명, 난방, 가스, 환기, 엘리베이터, 외출/방범, 경비실, 세대 통화, 기록, 공지, 설정(세대 비밀번호) |
| | 비디오폰 | 왼쪽 화면 + [모니터][통화][문열림][경비실][인터폰][종료] |
| | 인터폰 | 수화기형 음성 전용, LCD + 키패드 |
| | 비디오폰(기본형) | 인터폰(세대 통화) 기능 없음 — 세대 통화는 경비실 교환 |
| | 인터폰(단순형) | 다이얼 키패드 없음 — 세대 통화는 경비실 교환 |
| 세대 외부 | 도어카메라 | 영상 + 음성 송출 |
| | 도어폰 | 음성만 송출 |
| | 로비폰 | 카메라·LCD·키패드·[호출][경비실][취소][열쇠]·RF 카드 리더 |
| | 경비실기 | 관제 콘솔: 모니터(호출 영상·CCTV), 호출 대기 목록, 키패드, 수화기 |
| 관리 | 단지 대시보드 | 큰 지도에서 구획 편집 |
| | 관리 컴퓨터 | 단지 현황, 카드 등록·관리, 비밀번호, 공지사항 |
| 세대 설비 | 스마트 조명·온도조절기·가스밸브·환기장치·엘리베이터 호출 연동기 | 홈 링커로 연동한 세대의 월패드에서 제어 |

## 관리 비밀번호
- 모든 기기의 설정 메뉴는 처음엔 바로 들어갈 수 있습니다.
- 설정 화면에서 **관리 비밀번호**(숫자 4~8자리)를 정하면, 이후에는 그 비밀번호를 눌러야 설정 메뉴에 들어갈 수 있습니다. 설정 화면에서 해제도 가능.

## 외출/방범모드 · 동체감지기
- **외부 동체감지기**(집 외부 벽), **실내 동체감지기**(세대 안)를 설치하고 **홈 링커**로 세대와 연동합니다.
- 월패드(외출/방범) · 비디오폰([방범]) · 다이얼 인터폰([외출 설정])에서 설정 — **비밀번호 필요 없음**.
  - 기본형 비디오폰(인터폰 기능 없음)과 단순형 인터폰(다이얼 없음)에는 외출/방범 기능이 없습니다.
- 설정 후 **90초 유예**(집을 나갈 시간) 뒤 동체 감지 시작.
  - 외출모드: 실내·외부 감지기 모두 작동 (조명 소등·가스 잠금·환기 정지)
  - 방범모드: 외부 감지기만 작동 (집 안 사람은 감지하지 않음)
- 감지기 앞에서 **벽에 가리지 않은** 사람·동물이 보이면 **경비실기에 경보**(경보음 + 목록, [확인]으로 정리).
- 해제는 **세대 비밀번호**를 눌러야 합니다 (세대 비밀번호가 없으면 바로 해제).

## 경비실기 외출/재실 · 교환
- **외출**: 키패드로 **우회 경비실 번호**를 누른 뒤 [외출]. 외출 중에는 이 경비실을 관할로 둔 기기의 호출이 우회 경비실로 갑니다. [재실]로 복귀.
- **교환**: 세대와 통화 중 → `동*호` 입력 → [교환] → 그 세대가 울림.
  - 상대가 받기 전에 [교환](취소)을 다시 누르면 교환을 취소하고 다른 세대를 다시 입력할 수 있습니다.
  - 교환 세대가 받으면 경비실과 통화 → 경비실에서 [종료]를 누르면 **두 세대끼리만** 통화가 이어집니다.

## 링커 (연동은 링커로만)
기기를 문 옆이나 같은 집에 둔다고 자동으로 연동되지 않습니다.
- **홈 링커**: 월패드·비디오폰·인터폰 우클릭(선택) → 도어카메라·도어폰·조명·온도조절기·가스밸브·환기장치·엘리베이터 연동기 우클릭 → 그 세대와 연동
- **도어 링커**: 비디오폰·월패드·인터폰·로비폰 우클릭(선택) → 문·다락문·울타리 문 우클릭 → 연동 (다시 누르면 해제)
  - 로비폰의 문열림(통화·비밀번호·카드)은 로비폰에 연동한 문을, 세대 현관 문열림은 그 세대 기기에 연동한 문을 엽니다.
- 웅크리고 대상 우클릭: 연동 해제 · 웅크리고 허공 우클릭: 선택 해제

## 단지 대시보드
- 지도 위를 **누르고 끌면** 새 구획(단지)이 생깁니다.
- 구획을 **클릭**해 여러 개 선택 → **[묶기]**로 같은 단지, **[분리]**로 각각 다른 단지.
- 같은 단지의 구획이 맞닿으면 **맞닿은 부분의 경계선이 사라져** 하나의 단지 모양으로 보입니다.
- 모든 연동(호출·카드·비밀번호·설비)은 **같은 단지 안에서만** 됩니다.

## 통화
- 통화가 연결되면 조작화면 오른쪽에 **대화창**이 열리고, 입력하면 상대 기기로 전달됩니다(근처 채팅도 전달).
- 도어카메라·로비폰에서 온 호출은 월패드·비디오폰·경비실기 화면에 **실시간 영상**으로 나옵니다.

## 번호 (0~9999)
- 월패드·비디오폰·인터폰: 관할경비실 + 동 + 호 / 로비폰: 관할경비실 + 동 + 로비번호 / 경비실기: 경비실번호
- 경비실 호출은 관할경비실 번호가 같은 경비실기 우선.
- 로비폰은 동 번호가 같은 세대 호출, 동 9999(단지 외곽)는 단지 안 모든 동·호 호출.

## 공동현관 출입 (로비폰)
| 동작 | 단지 출입용 로비폰 (9999동) | 동 로비폰 |
|---|---|---|
| 세대 호출 | 동 → [호출] → 호 → [호출] | 호 → [호출] |
| 세대 비밀번호 출입 | 동 → [호출] → 호 → [열쇠] → 비밀번호 → [호출] | 호 → [열쇠] → 비밀번호 → [호출] |
| 공용 비밀번호 출입 | 대기 상태에서 [호출] → 공용 비밀번호 (맞으면 바로 열림) | 같음 |
| 세대 비밀번호 변경 | 불가 | 대기 상태에서 [열쇠] → 호 → [호출] → 기존 비밀번호 → [호출] → 새 비밀번호 → [호출] |

- 세대 비밀번호 초기값은 **1234**.
- 로비폰에서 세대 비밀번호를 바꿀 수 있는 건 **기본형 비디오폰·단순형 인터폰만 있는 세대**뿐입니다. 월패드·비디오폰·다이얼 인터폰이 있는 세대는 **그 세대 내부기기에서만** 변경합니다 (월패드 설정 · 비디오폰 [⚙] · 인터폰 [⚙] 설정 화면).
- 카드: **카드등록용 카드**를 등록하면 **출입용 카드**가 나옵니다. 카드를 들고 로비폰 우클릭.
- 로비폰 [⚙](관리 비밀번호 확인) → 2 관리자 모드:
  1 공용 비밀번호 변경 · 2 카드 등록 · 3 손에 든 카드 삭제 · 4 카드 번호로 삭제 · 5 카드 전체 삭제 · 6 번호 설정 · **7 공용 비밀번호 사용/미사용** · **8 세대 비밀번호 출입 사용/미사용**
- **공용 비밀번호**(출입용)와 **관리 비밀번호**(설정·관리자 메뉴 진입용)는 서로 다른 비밀번호입니다.
- 일반 로비폰은 그 동의 카드만, 단지 외곽 로비폰(9999동)은 단지 전체 카드를 관리합니다.

## 빌드
`./gradlew build` → `build/libs/`. push 할 때마다 GitHub Actions가 jar를 `build-output` 브랜치에 올립니다.
